# Границы продукта

## Назначение

Продукт — самостоятельная сборка Chromium для изолированных, повторяемых
браузерных профилей с согласованным представлением параметров устройства.
Допустимые целевые сценарии: тестирование веб-приложений, исследование
fingerprinting и защита приватности на системах и ресурсах, где оператор имеет
право это делать. Проект не гарантирует обход механизмов безопасности,
антифрода или правил стороннего сервиса.

## Обязательный конечный результат

Для каждой поддерживаемой настольной ОС поставляется подписываемый пакет,
который содержит браузер, локальную панель управления и сведения о сборке.
Оператор может создать, проверить, запустить, остановить, экспортировать и
удалить профиль. Одновременно запущенные профили имеют разные каталоги данных
и не разделяют cookies, cache, Service Workers, permissions или секреты.

Запуск принимается только если профиль полностью валиден и применён до
создания первого renderer. Частичное применение либо незаметная подстановка
значений хоста запрещены: запуск завершается диагностикой без секретных
данных.

## Объём первой готовой версии

- одна зафиксированная ветка Chromium и настольные Windows, macOS и Linux;
- локальные профили и один локальный оператор;
- настраиваемый регион профиля и HTTP(S)/SOCKS5 proxy на профиль, включая
  authentication и явные правила DNS;
- согласованные IP, geolocation, locale, timezone и языковые представления;
- подмена наблюдаемых параметров CPU, памяти, GPU и display в пределах
  поддерживаемых аппаратных классов;
- воспроизводимая release-сборка и автоматизированная проверка;
- миграция формата профиля и Chromium только как явная операция.

Не входят: мобильные платформы, командный облачный сервис, продажа готовых
«личностей», имитация другого browser engine и синхронизация пользовательских
данных через стороннее облако, Cloudflare Pages или GitHub Pages. Эти исключения
устраняют неподтверждённые обязательства, но не запрещают отдельное будущее
решение.

## Существенные ограничения

Браузер не может достоверно изобразить любое произвольное устройство. Сайт
наблюдает также IP/ASN, TLS/HTTP fingerprint, задержки, поведение пользователя,
учётную запись и признаки ОС. Поэтому продукт обещает **внутреннюю
согласованность выбранного поддерживаемого класса**, а не неотличимость от
любого физического устройства. Профили, несовместимые с текущей ОС, backend
графики или возможностями Chromium, должны отклоняться.

Фиксация версии нужна для воспроизводимости, но оставлять сетевой браузер без
security fixes недопустимо. Неизменяемая базовая линия сохраняется как факт,
а обновление выполняется отдельным решением и новой линией.
